# WittLab PPT Template Skill

这是一个 Codex skill，用于把用户提供的文本、图片、表格、链接或笔记整理成简洁的 PPT 内容，并严格填入内置模板。

## 用途

- 基于已有材料生成组会汇报、周报或项目进展 PPT。
- 基于文稿、作品说明或项目素材生成 showreel / 展示文案类 PPT。
- 清理或改写已有 PPT，使内容更简洁，同时保留模板风格。

## 内置模板

- `template/组会周报项目进展模板.pptx`：适合 InLab 组会、周报、项目进展、研究进度、实验进度、论文写作进度、导师反馈类汇报。
- `template/Showreel展示文稿模板.pptx`：适合 showreel 文稿、作品集/项目展示文案、展览讲述、demo 视频脚本、展示叙事、对外作品总结。

## 使用方法

1. 将本仓库作为 skill 安装到 Codex 的 skills 目录，或直接把仓库内容复制到 `~/.codex/skills/lab-report-ppt/`。
2. 在 Codex 中说明你的数据源和目标，例如：

   ```text
   用 lab-report-ppt，把这些本周学习笔记整理成组会周报 PPT。
   ```

   ```text
   用 lab-report-ppt，根据这份项目介绍生成 showreel 展示文稿。
   ```

3. 如果没有指定模板，Codex 会根据用途推荐一个模板；用途不明确时会让你在两个模板中二选一。

## 原则

- 只使用用户提供的数据源，不编造事实、引用、实验结果或日期。
- 尽量简洁整理文本，不把长篇笔记原样堆进 PPT。
- 严格保留所选模板的版式、字体、颜色和整体风格。
